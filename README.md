# Kito

Kito is an expressive, interactive, and playful desktop companion that can imitate real emotions. Kito is cute, can react, and lets you play games with it. The Kito model has been 3D printed and tested.

## Features

- Expressive reactions
- Interactive behavior
- Playable games
- Emotion-inspired animations
- 3D-printable physical desktop companion
